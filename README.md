# ResumeIQ – AI Resume Intelligence

ResumeIQ is an AI-powered resume analysis platform that helps students and job seekers understand their resume, evaluate job compatibility, identify skill gaps, and receive personalized career guidance.

The application combines resume parsing, ATS analysis, skill-gap analysis, career recommendations, and AI-powered career assistance in a single web application.

---

## 🚀 Features

### 1. Resume Analysis

Upload a PDF resume and ResumeIQ automatically extracts and analyzes its content.

It identifies:

- Candidate information
- Email
- Phone number
- Technical skills
- Resume sections
- Projects / experience
- Certifications / achievements
- Resume word count
- Overall resume score

---

### 2. ATS Resume Matching

ResumeIQ compares a resume against a specific job description.

It provides:

- ATS match score
- Matching skills
- Missing skills
- Resume-only skills
- Matched keywords
- Missing keywords
- ATS score breakdown

This helps users understand how well their resume matches a particular job.

---

### 3. Skill Gap Analysis

The Skill Gap module compares the skills detected in the resume with skills identified from the target job description.

It provides:

- Required skills
- Matched skills
- Missing skills
- Skill coverage percentage
- Skill development recommendations

---

### 4. Career Recommendation

ResumeIQ includes a rule-based career recommendation engine.

It analyzes the candidate's detected skills and identifies suitable career paths such as:

- Backend Developer
- Frontend Developer
- Full Stack Developer
- Machine Learning Engineer
- Data Analyst
- Other technology roles

The recommendation engine provides a ranked set of possible career directions.

---

### 5. Gemini AI Career Intelligence

ResumeIQ uses Google Gemini to provide deeper career analysis based on the resume and the career recommendations generated by the system.

The AI analysis includes:

- Recommended career
- Career summary
- Current strengths
- Missing skills
- Recommended skills
- Recommended projects
- 30-day roadmap
- 60-day roadmap
- 90-day roadmap
- Final career advice

---

### 6. AI Career Assistant

ResumeIQ also provides a conversational AI assistant.

Users can ask questions about their resume, for example:

- What should I improve in my resume?
- What skills am I missing?
- Which career is best for me?
- How can I improve my ATS score?
- What projects should I build?
- What should I learn next?

The assistant uses the uploaded resume as context when generating responses.

⚙️ Installation
1. Clone the repository
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ResumeIQ
2. Create a virtual environment
Windows
python -m venv .venv

Activate it:

.venv\Scripts\activate
Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
3. Install dependencies
pip install -r requirements.txt
4. Configure environment variables

Create a .env file in the project root.

Example:

GEMINI_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key

GEMINI_MODEL=gemini-2.5-flash
GROQ_MODEL=openai/gpt-oss-20b

Do not commit .env to GitHub.

▶️ Running the Application
Start the FastAPI backend
uvicorn backend.main:app --reload

The backend will run at:

http://127.0.0.1:8000
Open the frontend

Open:

frontend/index.html

You can open the HTML file directly in the browser or serve the frontend using a local web server.

🧠 AI Architecture

ResumeIQ uses two AI providers for different purposes.

Google Gemini

Gemini is used for:

Career intelligence
Career summaries
Skill recommendations
Project recommendations
Career roadmaps
Final career advice
Groq

Groq is used for:

Resume-aware conversational assistance
Resume improvement questions
Career questions
Skill discussions
Career guidance

The core resume processing and scoring system does not depend entirely on generative AI. Resume extraction, parsing, skill detection, ATS matching, and career recommendation use application logic and rule-based processing.

📊 Resume Scoring

ResumeIQ calculates an overall resume score using multiple factors, including:

Contact information
Resume sections
Skills
Projects / experience
Certifications / achievements

The score is an analytical indicator created by ResumeIQ.

It should not be considered an official score from a specific Applicant Tracking System (ATS).

🔐 Security
API keys are stored using environment variables.
.env should not be committed to GitHub.
Resume files are processed by the backend.
Production deployments should use HTTPS.
Authentication and proper data protection should be implemented before handling sensitive production data.
⚠️ Current Limitations

ResumeIQ is currently an MVP / portfolio-level application.

Current limitations include:

PDF extraction depends on selectable text.
Scanned/image-only resumes require OCR, which is not currently implemented.
Resume name detection may fail for some resume formats.
ATS skill extraction is currently rule-based.
Some job-description requirements may not be detected as skills.
Keyword matching can include generic job-description terms.
No user authentication system.
No database or persistent resume history.
No production job-search integration.
No automated deployment pipeline.
